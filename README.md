\# CompeteIQ — NEXORA AI



AI-Powered Competitive Intelligence Platform.



CompeteIQ helps businesses monitor competitors, analyze market developments, remember historical events, and generate strategic recommendations.



\## Core Technologies

\- React and Vite

\- Python and FastAPI

\- Ollama

\- BAND AI

\- Hindsight Memory

\- SQLAlchemy



\## BAND AI Agents

1\. Research Agent

2\. Product Intelligence Agent

3\. Market Intelligence Agent

4\. Financial Intelligence Agent

5\. Historical Intelligence Agent

6\. Risk Analysis Agent

7\. Strategy Agent



\## Hindsight Memory

\- Retain: Store historical intelligence.

\- Recall: Retrieve previous information.

\- Reflect: Generate insights from memory.
