# CompeteIQ — Demo Screenshot Guide

Use genuine screenshots from the running application. Do not create fake execution evidence.

## Required Screenshots

1. **Dashboard:** CompeteIQ home page.
2. **Company Profile:** NEXORA AI company information.
3. **Competitive Intelligence:** Competitor analysis results.
4. **BAND AI:** Actual agent execution or collaboration logs.
5. **Hindsight Retain:** Successful memory storage.
6. **Hindsight Recall:** Retrieved historical information.
7. **Hindsight Reflect:** Insights generated from stored information.
8. **Strategy Output:** Final strategic recommendations.
